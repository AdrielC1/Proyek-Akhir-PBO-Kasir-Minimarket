    Ringkasan 4 Lapisan Komponen GUI SI-RITEL (Urutan Materi Slide PPT)

    Lapis 1: Top-Level Window

    JFrame (LoginView, MainFrame) sebagai jendela utama, serta JDialog untuk modal konfirmasi, pratinjau struk, dan laporan A4.

    Lapis 2: Container & Layout

    RoundedCardPanel, JScrollPane, dan JLayeredPane yang diatur tanpa null layout memakai BorderLayout, CardLayout, GridBagLayout, GridLayout, dan BoxLayout.

    Lapis 3: Komponen Input & Tombol

    Variasi lengkap: JTextField, JPasswordField, JComboBox (RoundedComboBoxUI), JRadioButton, JCheckBox, JSpinner, ModernDatePicker, JTable, dan RoundedButton.

    Lapis 4: Feedback & Kontrak UI

    Tema terpusat UITheme, peringatan InlineAlertPanel, ToastManager, ModernModal, pencetak Printable (ReceiptSupport, LaporanPrinter), dan interface RefreshableView.
